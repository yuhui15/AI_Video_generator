# 图片抓取与 CLIP 筛选工具

这是一个 Windows 本地图片抓取工具。网页控制台可以：

- 从 comprehensive_63_metrics 中选择一个指标，调用 Mistral Ministral 14B 改写 high/low 图片搜索词并在抓取前显示；
- 在 looksmax.org 站内搜索结果中查找图片；
- 输入自己的图片搜索话题；
- 调整 CLIP 筛选阈值、每个级别目标图片数和输出目录；
- 查看抓取任务状态和实时日志。

网页服务只绑定到本机 127.0.0.1，不对局域网或公网开放。Ministral 14B 通过 Mistral API 远程调用，不会下载模型权重到本机。CLIP 模型在首次筛选图片时会从 Hugging Face 下载并在本机运行。

## 系统要求

- Windows 10/11
- Python 3.10 或更新版本（建议 Python 3.11，需勾选“Add Python to PATH”）(已经提供安装包, 在根目录里面)
- 已安装 Google Chrome
- 可访问 Hugging Face、Bing 图片搜索和图片来源网站的网络连接
- 磁盘空间：Python、PyTorch 和 Transformers 依赖占用较大；首次运行还会下载 CLIP 模型
（安装python的时候注意选择 cutomize installation，然后把 optional features 和 advanced options 的所有选项全部勾选，然后点击install进行安装）

## 配置 Mistral API Key

使用指标改写或生成小红书文案时需要 Mistral API Key。在网页粘贴从 Mistral 控制台创建的 API Key，再点击“绑定 API Key”。密钥只保存在运行控制台的本机 Python 进程内存中：改写搜索词时传给改写子进程，生成文案时由本机服务用于 API 请求；不会写入项目文件、浏览器存储、URL 或任务日志。关闭控制台服务后密钥会清除，需要重新输入。

绑定密钥的接口仅接受当前本机网页的同源请求；密钥由本机服务内存用于搜索词改写和小红书文案生成。页面上的“清除 API Key”按钮会立即从服务内存中删除它。密钥不会通过 API 回传，页面只显示是否已绑定。请确认 Mistral 账户已开通 API 调用权限和额度，并避免在不可信设备上输入。

自定义搜索话题不需要 Mistral API Key。

## 使用网页

### 选择指标、预览改写并抓取

1. 选择“选择一个指标 + Ministral 14B 改写”。
2. 绑定 Mistral API Key，按名称搜索并选中一个指标。
3. 点击“改写搜索词”，网页会显示 high / low 两条改写结果；确认后再开始抓取。
4. 设置 CLIP 严格度、每个级别目标图片数和保存目录。
5. 点击“开始抓取”。

图片通过 Bing 图片搜索，并将查询限制为 site:looksmax.org；这会查找 looksmax.org 页面关联的图片结果。图片文件本身可能由论坛帖子引用的外部图床托管。每个指标在脚本中定义有 high 和 low 两种搜索级别；目标图片数分别应用到每个级别。保存目录始终使用改写前选中的预设指标名称（例如 面部长宽比\high 和 面部长宽比\low），改写后的搜索词只用于检索，不会用作目录名。

### 自定义搜索话题

选择“自定义搜索话题”，输入图片搜索短语，例如:
`adult male fashion model portrait`

自定义话题会直接作为 Bing 图片搜索词，不需要 Mistral API Key。

### 准备小红书图文草稿

1. 在网页上先绑定 Mistral API Key，再切换到“小红书发布”。
2. 选择“High / Low 对比”模式，选一个含 high 和 low 子文件夹的指标目录；或选择“话题文件夹”模式，选有图片的话题目录。
3. 设置抽取数量、填写可选的创作者 Prompt，然后生成草稿。对比模式会从 high、low 各抽取相同数量，话题模式会从所选目录递归抽取；生成的文案短小精炼、不使用 Markdown 格式，文案最后推荐 yanzumeixue.com 网站，并说明：*想知道自己颜值是什么水平，请使用这个网站*，每篇最后会自动附加颜祖美学推广图。
4. 检查并编辑图片、标题和正文后，点击“打开小红书编辑页并填入草稿”。首次使用时在弹出的 Chrome 窗口中登录。
5. 确认小红书编辑页的图片顺序和文案，再由你手动点击平台的“发布”按钮。程序不会自动提交公开帖子。

推广尾图由 `xiaohongshu_publisher\assets\yanzumeixue_promo.png` 首次运行时生成；如需更换设计，可将自制推广图保存到该位置。Chrome 登录状态保存在 `xiaohongshu_publisher\.browser_profile`，该目录已加入 Git 忽略规则；不要分享或提交该目录。

## CLIP 严格度说明

阈值范围为 0.35 到 0.95。数值越高，CLIP 越倾向于拒绝图片，可能导致通过筛选的图片较少。CLIP 当前使用通用的真人面部/照片描述进行图文相似度判断；它不是精确的人脸检测器，也不能准确测量或验证外貌指标。请将筛选结果视为自动化候选筛选，而非专业判断。
